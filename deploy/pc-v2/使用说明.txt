Botagent 插线部署工具 v2
================================

一句话：插上手机，双击 exe，点「开始部署」。

需要什么
--------
· Windows 7 以上（推荐 Win10/11）
· 一根能传数据的 USB 线
· 手机已开「开发者选项」里的「USB 调试」
  （小米/红米还要开「USB 安装」→ 设置 → 更多设置 → 开发者选项）
· 这份压缩包里已经带了 adb，不用另外装

怎么用
------
1. 解压到一个文件夹（路径别带中文也行，但别放 C:\Program Files）
2. 把 APK 放到同一个文件夹，改名成 Botagent.apk
   （或者部署时点「选择…」自己挑）
3. 双击 BotagentDeploy.exe
4. 手机插上电脑，手机上弹「允许 USB 调试吗」→ 点「允许」
5. 工具里点「刷新」，选中设备
6. 点「开始部署」

它会做什么
----------
· 装 APK（覆盖安装，不动数据）
· 小米的「继续安装」弹窗会帮你自动点掉
· 装完可选：打开无障碍、启动 App
· 最后显示装上的版本号

出问题怎么办
------------
「没有检测到手机」
  → 换根线 / 换个 USB 口；手机上重新点一次「允许 USB 调试」

「INSTALL_FAILED_USER_RESTRICTED」
  → 小米/红米：开发者选项 → 打开「USB 安装」

「INSTALL_FAILED_UPDATE_INCOMPATIBLE」
  → 手机上装的是别的签名版本，先卸载旧的再装

装完以后
--------
打开 App，按 4 步向导走：
① 填 QQ 号 + API Key
② 开无障碍 + 关电池优化
③ 创建容器 → 安装 NapCat → 导入 QQ 安装包 → 启动协议端
④ 启动机器人 → 扫码

法律说明
--------
本工具不包含、不下载腾讯 QQ 客户端。
NapCat 按许可证原样内置（见 App 内 assets/napcat/）。
非商业用途，与腾讯、NapCat 官方均无隶属关系。
