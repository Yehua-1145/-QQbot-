懒人选项：单 APK 版（v2 实验版）
不想装 Termux、不想开 USB 调试？有个版本把 Python 运行时直接打进 APK。
装完只需要填 QQ 号 + API Key，点一下「启动」就能跑。
下载 Botagent-v2.0-beta.apk（18 MB） 看 v2 使用说明
实验版。QQ 登录仍然需要 AstrBot（协议端，扫码那步没法省）；
想要稳定、已验证的流程，就走下面四步。
1
装 QQ 协议端（AstrBot App）
QQ 登录靠它。它自带 Ubuntu + Linux QQ + NapCat，不用 root。
装完打开 → 扫码登录你的 QQ 小号 → 进设置把 WebSocket 端口改成 3001。
下载轻量版（约 95 MB） 完整版（约 1 GB，功能全）
两个任选一个。装完必须确认 WebSocket 端口 = 3001，否则下一步连不上。
2
装 Termux（跑程序的环境）
从 F-Droid 装，不要用应用商店里那个旧版（会装不上包）。
打开 F-Droid 下载页
装完先打开一次，等它自己初始化完（几十秒），看到 $ 提示符就行。
3
粘一条命令，等它自己装
在 Termux 里长按屏幕 → Paste（或音量键 + V）粘贴下面这条，回车。 大约 3~8 分钟，中途会问几个问题（QQ 号、API Key）。 
pkg install -y curl && bash -c "$(curl -sL https://cdn.jsdelivr.net/gh/Yehua-1145/-QQbot-@main/install_phone.sh)"
如果卡住不动：按 Ctrl+C 停掉，先单独跑 pkg install curl 看看有没有报错。
4
打开控制台
手机浏览器访问下面这个地址（本机访问不用 token）： 
http://127.0.0.1:8080/app
直接打开
进不去就看 Termux 里最后几行输出——通常是 8080 被占用，或者在 ~/aibot 里跑 bash stop.sh 再 bash start.sh。

装不上？先看这几条

提示「Could not resolve host」/ 下载很慢

手机网络解析不了 GitHub。脚本已经内置三个下载源自动切换（直连 → gh-proxy → ghproxy.cc）， 全失败的话：电脑/手机浏览器手动下 Botagent-v1.1.zip，放到 /sdcard/Download/，然后在 Termux 里跑：

bash install_phone.sh --zip /sdcard/Download/Botagent-v1.1.zip
Termux 里 pkg 报错 / 装不上 python

多半是镜像问题。手动换成官方源再试：

echo "deb https://packages.termux.dev/apt/termux-main stable main" > $PREFIX/etc/apt/sources.list
apt update && pkg install -y python
控制台能开，但 QQ 里机器人不理我

说明 3001 没通，也就是 AstrBot 那边没起来。检查顺序：

  • AstrBot App 里 QQ 是否显示「在线」
  • 它的 WebSocket 端口是否 3001（默认可能是别的）
  • 在 Termux 跑 bash ~/aibot/status.sh，看 napcat 那行
想让 AI 替你点屏幕（可选）

解压包里有 手机端手动部署/Botagent.apk，装上，去 设置 → 无障碍 → 已下载的服务 → Botagent 打开。之后在 QQ 里说 「帮我把设置里的护眼模式关掉」它就能自己点了。

注意：重装 App 后无障碍会被系统关掉，需要重新开一次。

怎么关掉 / 重启 
bash ~/aibot/start.sh     # 启动
bash ~/aibot/stop.sh      # 停止
bash ~/aibot/status.sh    # 看状态

想开机自启：装 Termux:Boot，然后执行一次 bash ~/aibot/start.sh 的注册步骤（脚本已写好 ~/.termux/boot/）。
