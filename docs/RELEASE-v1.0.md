## 亮点

- **免 root**：全部跑在 Termux + proot Ubuntu 里，不需要刷机不需要权限
- **一键部署**：Windows 上插线 → 填 QQ 号 → 点「开始部署」，剩下的自动做完
- **没 root 也能全自动**：通过 adb 驱动 Termux 完成输入，不用自己敲命令
- **体积小**：源码 350 KB + 电脑工具 11 MB（同类方案通常是 1 GB 级 APK）
- **自带控制台**：手机上装个 App，聊天、看状态、换模型、改人设都在里面
- **多服务商**：DeepSeek / OpenAI / 通义千问 / 本地 Ollama / 任何 OpenAI 兼容接口

## 关于功能边界：聊天机器人 vs 完整 Agent

| 能力 | 无 root | 有 root |
|---|---|---|
| QQ 聊天、扫码登录 | ✅ | ✅ |
| 发图（图库 / 联网搜图） | ✅ | ✅ |
| 人设、多服务商、控制台 | ✅ | ✅ |
| 执行命令、读写任意文件 | ❌ | ✅ |
| 截屏、点按、全局操作手机 | ❌ | ✅ |
| 静默装应用、发短信、调音量 | ❌ | ✅ |

**没有 root**：会聊天、会发图的 QQ 机器人。
**有 root**：能真正执行「帮我截个图」「装个 App」「看下电量」的 Agent。

部署工具会自动检测 root 并说明走哪条路径。

## 这次包含什么

### 手机端

- QQ 私聊、群聊（@ 触发）、关注账号自动接话
- 流式对话，边生成边发

五个页签：

| 页签 | 功能 |
|---|---|
| 对话 | 直接在手机上跟它聊 |

设置里还有：

- **人设编辑**：写名字、性格、说话方式
- **使用说明**：首次打开自动弹出
- **图库管理**：深度抓图开关（含风险确认）、每日自动换新、配置备份/恢复
- **意见反馈**：App 内直接提交

### Windows 一键部署工具

自动完成：

1. 检测设备、判断有无 root
2. 手机没装 Termux → 自动下载并安装
3. 配置存储权限、后台运行、电池优化白名单、开机自启
4. 推送程序 + 配置，生成访问 token
5. 启动服务，等端口就绪
6. 装上手机控制台 App 并打开

另外：

- **一键卸载**：可选保留配置，可选连 Linux 容器一起删
- **装控制台 App**：单独的按钮，随时重装
- **API Key 可留空**：装好后在手机控制台里填

## 快速开始

### 1. 手机准备

打开「开发者选项 → USB 调试」，插上数据线，手机上点「允许」。

### 2. 电脑部署

解压后进入 `Windows一键部署`，双击 `BotagentDeploy.exe`：

```
① 选服务商        DeepSeek / OpenAI / 通义 / 本地 Ollama / 自定义
② 填 API Key      可以留空，装好再填
③ 填你的 QQ 号    主人的 QQ
④ 点「开始部署」
```

有 root 全自动；没 root 勾选「无 root 也全自动」即可。

### 3. 扫码登录

手机上打开 **Botagent** App → 控制台 → 用要当机器人的 QQ 扫码。

状态变「在线」就可以在 QQ 里说话了。

## 配置要求

### 手机

| 项 | 最低 | 推荐 | 说明 |
|---|---|---|---|
| 系统 | Android 7.0 | Android 10+ | 实测环境 LineageOS 18.1（Android 11） |
| 架构 | arm64-v8a | arm64-v8a | Linux QQ 只提供 arm64 包，**32 位手机装不了** |
| 内存 | 3 GB | 4~6 GB | 常驻约 600~900 MB（QQ + 协议端 + Python） |
| 可用存储 | 3 GB | 5 GB | 容器 ~1.5 GB + 图库 + 附件缓存，详见下表 |
| CPU | 骁龙 660 级 | 骁龙 835 级 | 实测小米 6 流畅 |
| root | 不强制 | Magisk | **完整 Agent 能力需要 root**，详见上一节 |

存储占用参考：

```
proot Ubuntu 根文件系统     约 500 MB
Linux QQ + 运行库           约 700 MB
NapCat / Python 依赖        约 300 MB
图库（默认上限）            约 400 MB
日志与缓存                  约 100 MB
------------------------------------
合计                        约 2 GB（首次部署会下载约 2 GB）
```

### 网络

| 场景 | 要求 |
|---|---|
| 部署阶段 | 需要能访问 GitHub（下载 Termux）和 apt/pip 源，下载约 2 GB |
| 运行阶段 | 需要能访问你选的大模型接口 |
| 图库抓图 | 需要能访问对应图源，部分站点可能需要代理 |

国内网络建议先开代理，或者用部署工具里内置的重试（它会自动换源）。

### QQ 账号

- **建议用小号**：非官方协议端有封号风险，别用主号
- 需要能扫码登录（手机 QQ 扫一扫）
- 部分账号会触发短信验证，需要人工完成一次

### 电脑（仅一键部署需要）

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 数据线 | 支持数据传输（有些线只能充电） |
| 驱动 | 多数情况免驱，异常见下方「驱动与连接」 |
| 其它 | `adb.exe` 已内置在发布包里，不用自己装 |

macOS / Linux 用户可以用「手机端手动部署」方式，不需要电脑端工具。

### 驱动与连接

**原理**：部署走的是 **adb（Android Debug Bridge）** 通道，不依赖手机助手，也不需要安装手机厂商的全家桶。

**正常情况**：

- Windows 10 / 11 自带 **WinUSB** 通用驱动，插上并在手机上点「允许 USB 调试」后即可识别
- 设备管理器里应出现 **Android Device → Android ADB Interface**（或类似名称），且无黄色感叹号

**判定是否连接成功**：打开命令提示符，执行

```bat
adb devices
```

| 输出 | 含义 | 处理 |
|---|---|---|
| `<序列号>    device` | ✅ 正常 | 可以开始部署 |
| `<序列号>    unauthorized` | 手机未授权 | 看手机屏幕，点「允许」，勾选「一律允许」 |
| `<序列号>    offline` | 连接异常 | 拔插数据线，或 `adb kill-server` 后重试 |
| 列表为空 | 未识别 | 见下方排查 |
| `adb: command not found` | 没找到 adb | 用发布包内置的 `adb.exe`，不要用其它版本 |

**识别不到时的排查顺序**：

1. **换线**：部分数据线只有充电针脚，必须用支持数据传输的线
2. **换口**：优先插主板后置 USB 口，避开前置面板和 USB Hub
3. **看设备管理器**：出现「未知设备 / Android」带黄色感叹号 → 装厂商 USB 驱动
   - 小米：Mi USB Driver 或小米助手（装完可卸载，驱动会保留）
   - 高通平台通用：Google USB Driver 也可尝试
4. **关掉会抢占 adb 的软件**：豌豆荚、手机助手、360 手机卫士、各类刷机工具会同时占用 adb 服务，表现为 `offline` 或列表为空。退出这些程序（必要时结束进程）后重试
5. **换一条 USB 2.0 口**：个别 USB 3.0 控制器与老机型兼容性差

**无线调试（可选，Android 11+）**：

不想用数据线可以走无线，但需要先用一次命令行：

```bat
:: 手机：开发者选项 → 无线调试 → 使用配对码配对
adb pair 192.168.1.x:配对端口
adb connect 192.168.1.x:调试端口
adb devices
```

连接成功后再运行部署工具，它会正常列出该设备。

> 注：无线调试对网络稳定性敏感，部署阶段建议还是用数据线，装完再拔。

## 常见问题

**检测不到设备**
换根数据线（有些只能充电），重新打开 USB 调试。

**提示未授权**
看手机屏幕点「允许」，勾选「一律允许」。

**小米 / MIUI 装不上**
开发者选项里打开「USB 安装」和「USB 调试（安全设置）」。

**无 root 自动化没成功**
确认装了官方 Termux，且首次初始化完成（出现 `~ $` 提示符）。

**拉不出二维码**
控制台点「重新生成二维码」。如果提示需要短信验证，去协议端后台完成验证。

**消息不回**
看控制台日志尾部，通常是 API Key 或网络问题。

**滑动有条白边**
用包内最新 `Botagent.apk`，旧版 App 有这个问题。

## 已知限制与反馈

### 这个项目还不完善

先把话说清楚：它是一个**个人项目**，能跑通、够自己用，但离「成熟产品」还有距离。下面这些是已知的短板，遇到了不必意外。

**兼容性**

- 只在**小米 6 / LineageOS 18.1（Android 11）+ Magisk** 上完整验证过
- 其它机型、其它 ROM 可能遇到：proot 启动失败、后台被系统杀、adb 识别异常
- 32 位（armeabi）手机**无法运行**（Linux QQ 只提供 arm64 包）

**能力边界**

- 没有 root → 只能聊天和发图，**没有工具能力**（详见上文功能边界）
- **语音消息、表情包：暂未支持，后续版本计划加入**（见下方「后续计划」）
- 视频消息、语音通话：暂无计划
- 群管理只做了基础功能（部分操作未实现）
- 单账号，不支持同时挂多个 QQ
- 记忆长度有限（上下文和长期记忆都有字数上限）
- 并发多人同时提问时会排队，响应会变慢

**稳定性**

- 依赖 NapCat + Linux QQ，**上游一改登录机制就可能失效**，需要等适配
- 二维码约 3 分钟过期，过期要手动重新生成
- proot 容器长时间运行可能被系统回收，需要保活（部署时已配白名单，但不保证）
- 图库抓图依赖外部图源，图源挂掉时会抓不到
- **没有自动更新**，升级需要手动重新部署或替换文件

**体验**

- 控制台是网页套壳，不是原生 App，动效和手感一般
- 界面文案只做了中文
- 首次部署要下载约 2 GB，网络差时很慢
