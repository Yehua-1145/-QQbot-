# Botagent v1.0.4 更新公告

> 这一版的重点：**它真的能动手操作手机了。**

---

## 一句话说明

以前它只能在聊天框里回你话；
现在你在 QQ 里说「打开哔哩哔哩，搜 安卓」，它会自己去点搜索框、填字、点搜索。

```
你：打开哔哩哔哩，搜 安卓
它：① 读界面  → ② 点搜索框 → ③ 填「安卓」→ ④ 点搜索 → ⑤ 回报结果
```

---

## 怎么用

**就是直接说人话**，不需要记命令：

```
「打开微信」
「把设置里的护眼模式关掉」
「帮我在淘宝搜一下机械键盘」
「往下翻，找到 4 月 5 号那条记录」
```

### 它是怎么做的

```
① 先读界面：拿到按钮文字和坐标
② 按文字点：不是瞎猜坐标
③ 等结果出现：确认这一步真的生效了，再做下一步
```

界面读不到控件（网页、游戏、图片）时，**自动改用 OCR 读屏**。

---

## 新增了什么

| 能力 | 说明 |
|---|---|
| **界面操作** | 读界面、按文字点、输入文字、滑动、返回 |
| **OCR 兜底** | 网页 / 游戏 / 图片界面也能读（离线，2~5 秒一屏） |
| **图标模板** | 纯图标按钮教一次就行，以后按图标点 |
| **视觉模型** | 纯图形界面可接 Qwen-VL / GPT-4o 等（选配） |

工具数量：**29 → 42**。

---

## ⚠️ 升级会多花几分钟

从 v1.0.4 起，点「开始部署」后**末尾会自动装 OCR 依赖**：

```
tesseract 5.5.4 + 中文语言包 + python-numpy
```

- 耗时 **1~3 分钟**
- **期间不要锁屏、不要拔数据线**
- 装失败不影响聊天，可以点界面上的「装OCR依赖」按钮重试
- 中文语言包已随安装包附带，不用联网下载

安装包从 16.85 MB 变成 **18.52 MB**（多了语言包）。

## 边界（照样说清楚）

**能做**

```
✓ 打开 App、点按、输入文字、滑动列表、返回
✓ 装应用、截图、发短信、调音量、执行命令
```

**做不到**

```
✗ 无 root 完全不行（只能聊天和发图）
✗ 认不出的图标要你自己裁一次模板
✗ 游戏画面这类纯图形界面，要额外配视觉模型
```

**安全**

```
· 涉及付款、删除、给别人发消息，它会先问你确认
· 这组功能只有主人能用，访客拿不到
· 每步操作后都会确认界面变化，走错了会说没做成，不会假装成功
```
