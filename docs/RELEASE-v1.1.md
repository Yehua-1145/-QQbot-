## 这个版本有什么

### 一、会操作手机（12 个界面工具）

在 QQ 里说人话就行：

```
「打开哔哩哔哩，搜 安卓」
「把设置里的护眼模式关掉」
「往下翻，找到 4 月 5 号那条」
```

它是「看清再点」，不是瞎猜坐标：

```
ui_dump  读界面（文字 + 坐标）
ui_tap   按文字点，找不到会返回候选
ui_type  填字    ui_swipe 滑动    ui_key 返回
ui_wait  等结果出现再走下一步
```

**实测**：让它"点进设置里的网络和互联网"，前台真的切到了 `Settings$SubSettings`。

### 二、读不到控件时的三层兜底

| 场景 | 用哪个 |
|---|---|
| 普通 App | `ui_dump`（0.5~1.5 秒） |
| 网页 / 游戏 / 图片界面 | `ocr_screen` / `ocr_tap`（2~5 秒，离线） |
| 长列表找不到 | `ocr_find`（自动一屏屏滑着找） |
| 加载中 / 动画 | `ocr_wait`（等文字出现） |
| 纯图标按钮 | `icon_save` 存模板 → `icon_tap`（2.5 秒） |
| 纯图形界面 | `see`（接视觉模型，需配 key） |

**实测**：`ocr_wait` 等「Botagent」出现用 2.9 秒；`icon_tap` 命中 0.72~0.98，换界面的模板 0.46 会被拒。

### 三、自动任务（新的）

设置 → 自动任务：

```
什么时候   每天固定时间 / 每隔 N 分钟
做什么     让 AI 去做（调模型）/ 执行命令
发到哪     指定 QQ、指定群、或发给自己
内容       一句提示词，或一条命令
```

每条任务都能：

```
[执行] 立刻跑一次      [编辑] 改完保存
[暂停] 临时关掉        [删除]
上次 11/6 14:12 · 下次 10.0 小时后
```

**实测**：

```
shell 任务  → task done: shellA -> 命令已执行（rc=0）
AI  任务   → sent 10 chars to 3372387921，1 秒完成
```

命令类还可以勾「把输出发给我」，结果直接发到 QQ。

### 四、这版修的问题

- **覆盖页没样式**：`#taskpage` 漏了浮层 CSS，导致页面被挤到最下面
- **改完 UI 看不到变化**：WebView 缓存，现在 `/app` 返回 `no-store`
- **`ui_tap` 不可靠**：界面在动时自动再 dump 一次；控件树为空时改用 OCR
- **任务会互相卡**：改成每任务独立线程
- **新建任务立刻触发**：保存时播种「上次 = 现在」，从下个周期开始
- **重启后错过的每日任务**：启动时补跑（最多 2 个）
- **时间输入框显示成空下拉**：安卓 WebView 对 `<input type=time>` 渲染异常，改文本框

## 边界

**能做**

```
✓ 开 App、点按、输入、滑动、返回
✓ 装应用、截图、发短信、调音量、执行命令
✓ 定时自己干活（每天 / 每隔）
```

**做不到**

```
✗ 无 root 完全不行（只能聊天发图）
✗ 游戏画面这类纯图形界面，要额外配视觉模型
✗ 认不出的图标要自己裁一次模板
✗ 任务检查粒度 20 秒（设 08:30 可能 08:30:20 触发）
```

**安全**

```
· 付款、删除、给别人发消息前会先问你确认
· 界面工具只有主人能用，访客拿不到
· 每步操作后确认界面变化，走错会说没做成
```
