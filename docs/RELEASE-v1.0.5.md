## 新增：自动任务

位置：控制台 → **设置 → 自动任务 → 进入自动任务**

### 能配什么

| 项 | 说明 |
|---|---|
| **什么时候** | 每天固定时间（如 08:30）／每隔 N 分钟 |
| **做什么** | 让 AI 去做（调用模型）／执行一条 shell 命令 |
| **发到哪** | 指定 QQ 号、指定群号，或留空发给自己 |
| **内容** | 一句提示词，或一条命令 |

### 例子

```
每天 08:30  让 AI 说一句今天的天气和一句提醒     → 发给我
每隔 120 分 让 AI 看看手机电量还剩多少            → 发给我
每天 23:50  执行 df -h 记录磁盘占用              → 不发给谁
```

### 界面

```
现有任务
  开着  每天 08:30 · 让 AI 去做 · 发给我
  今天天气怎么样，顺便提醒我带伞
  [暂停] [删除]

新建任务
  什么时候      [每天固定时间 ▾]
  具体时间      [08:30]
  间隔分钟数    [60]
  让它做什么    [让 AI 去做 / 说一句 ▾]
  发到哪        [123456789]   □ 这是群号
  具体内容      [textarea]
  [添加任务]
```

### 执行机制

- 机器人进程每 **20 秒**检查一次
- 「每天」同一天只跑一次；「每隔」按上次执行时间算
- 执行记录写在 `config.json` 的 `task_state` 里，重启不会重复跑
- 命令类任务出错只写日志，不会打扰你
- 最多 20 个任务

## 顺手修的两个问题（UI 相关）

1. **覆盖页没样式**：`#taskpage` 一开始没加进浮层 CSS，导致它按普通区块渲染、被挤到页面底下。已补独立样式（固定定位 + 滑入 + 内部滚动）。
2. **时间输入框显示成空下拉**：安卓 WebView 对 `<input type="time">` 渲染异常，改成普通文本框（占位 `08:30`，数字键盘）。

另外给 `ui_tap` 加了两层兜底：界面在动时自动再 dump 一次；控件树读不到时改用 OCR 找文字。

## 已知限制

- 任务由机器人进程执行，手机刚重启、机器人还没起来时不会跑
- 「每天」只精确到分钟，同一分钟只触发一次
- 命令类任务没有输出回传（只在日志里）
- 无 root 时命令类任务无效（只能跑提示词类）

**反馈**：仓库 Issues，或 App 内「设置 → 反馈」。
